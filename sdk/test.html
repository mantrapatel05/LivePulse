LivePulse — local smoke test

This page installs LivePulse the way a real customer would: one <script> tag, no manual init() call. Open the LivePulse dashboard in another tab (same project) to watch events and chat arrive here.

  1. Run the backend: cd LivePulse/backend && npm run build:sdk && npm run dev
  2. Seed a test project: npm run seed:test-project
  3. Open this file directly in a browser (no server needed for the HTML itself)

Chat bubble should appear bottom-right (chat is enabled below).
